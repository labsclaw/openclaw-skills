# Proveniência e fronteiras

Procedimento e helper escritos originalmente pela LabsClaw sob Apache-2.0.
Nenhum código, prompt ou skill de terceiros foi transplantado para este pacote.

- Pedido e correção do dr. Roger, 14/11/2026: empacotar o procedimento, com
  MiniMax/DeepSeek como avaliadores do resultado, e publicar no GitHub LabsClaw.
- A experiência local de destilação e revisão de skills motivou o pacote. Não
  publicar transcrições privadas, respostas brutas de modelos ou dados do usuário.
- [Artefato histórico de destilação](https://github.com/labsclaw/openclaw-skills/commit/48da95ed5db31be8cb6c4371384c30ee4a6eed78)
  é evidência de um trabalho antigo, não receita universal nem benchmark desta skill.
- [Fable Method](https://github.com/Sahir619/fable-method) foi uma referência
  de discussão de disciplina e avaliação. Este pacote não incorpora seus textos
  ou regras forçadas, nem materiais históricos de licença não estabelecida;
  princípios foram formulados independentemente a partir do contrato atual
  e casos verificáveis.
- `skill-optimizer.ps1`, que pertence a outra skill, usa heurísticas sobre
  correções. Seu número de patches não prova melhoria e ele não substitui este
  procedimento. O framework Microsoft SkillOpt também é um projeto distinto.

Revisão de fontes e licença faz parte de toda destilação: preservar licença de
recursos efetivamente copiados. A licença raiz deste pacote não relicencia uma
skill recebida como entrada. Não restaurar instruções históricas por associação.
